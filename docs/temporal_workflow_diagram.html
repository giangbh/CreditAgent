BƯỚC 4

Workflow Điều Phối Luồng 13 Agent (Sequential & Parallel Fan-out)

Hàm @workflow.run thực thi chuỗi 13 Agent qua workflow.execute_activity() kèm schedule_to_close_timeout=timedelta(seconds=30):

  • Bước 4.1 (A1 Intake): Chạy Activity A1, nhận về updated_state làm current_state ban đầu.
  • Bước 4.2 (Fan-out Barrier): Chạy song song 3 Activities A2, A3, A4 bằng asyncio.gather() trên cùng snapshot current_state. Sau đó gộp kết quả analyst_reports và audit vào current_state.
  • Bước 4.3 (Tuần tự A5 -> A13): Lặp tuần tự từ A5 đến A13, sau mỗi Activity sẽ cập nhật current_state cho bước tiếp theo.
# Step 1: A1 Intake a1_res = await workflow.execute_activity(execute_agent_activity, args=["A1", {}, scenario_id], schedule_to_close_timeout=timedelta(seconds=30)) current_state = a1_res.get("updated_state", {}) # Step 2: Parallel Fan-out A2, A3, A4 a2_task = workflow.execute_activity(execute_agent_activity, args=["A2", current_state, scenario_id], schedule_to_close_timeout=timedelta(seconds=30)) a3_task = workflow.execute_activity(execute_agent_activity, args=["A3", current_state, scenario_id], schedule_to_close_timeout=timedelta(seconds=30)) a4_task = workflow.execute_activity(execute_agent_activity, args=["A4", current_state, scenario_id], schedule_to_close_timeout=timedelta(seconds=30)) a2_res, a3_res, a4_res = await asyncio.gather(a2_task, a3_task, a4_task) # Merge branch reports for branch_res in (a2_res, a3_res, a4_res): branch_state = branch_res.get("updated_state", {}) if "analyst_reports" in branch_state: current_state.setdefault("analyst_reports", {}).update(branch_state["analyst_reports"]) # Step 3: Sequential A5 .. A13 for node in ["A5", "A6", "A7", "A8", "A9", "A10", "A11", "A12", "A13"]: node_res = await workflow.execute_activity(execute_agent_activity, args=[node, current_state, scenario_id], schedule_to_close_timeout=timedelta(seconds=30)) current_state = node_res.get("updated_state", current_state)
⬇️ (Mỗi Activity thực thi Logic Agent)
BƯỚC 5

Activity Execution: Tái Tạo State & Áp Dụng StatePatch

Hàm @activity.defn(name="execute_agent_node") nhận node_id, state_dict và scenario_id: 1. Tái tạo CreditState(**state_dict). 2. Chạy AgentRuntime(ScenarioModel(), ToolGateway()).run(node_id, state, scenario). 3. Áp dụng toàn bộ execution.patches vào state bằng apply_patch(). 4. Trả về updated_state snapshot mới nhất về cho Workflow.

@activity.defn(name="execute_agent_node") async def execute_agent_activity(node_id: str, state_dict: Dict[str, Any], scenario_id: str) -> Dict[str, Any]: scenario = SCENARIOS[scenario_id] state = CreditState(**state_dict) if state_dict else CreditState(...) runtime = AgentRuntime(ScenarioModel(), ToolGateway()) execution = runtime.run(node_id, state, scenario) for patch in execution.patches: apply_patch(state, replace(patch, base_state_version=state.state_version)) return { "node_id": execution.node_id, "patches": [...], "updated_state": state.public_snapshot() }
⬇️ (Ghi nhận Checkpoints & Kết thúc Workflow)
BƯỚC 6

Persistence Checkpoints & Trả Kết Quả Cho Client

Sau khi 13 Agent hoàn thành, TemporalWorkflowEngine ghi nhận 14 State Checkpoints & Audit Events vào cơ sở dữ liệu SQLite localDB (credit_agent.db), đồng thời hoàn tất Workflow Execution trên Temporal Server với trạng thái Completed.
